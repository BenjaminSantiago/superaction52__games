# Super Action 52 → GAMES

This is the repo of the actual SNES game source code and ROMS for Super Action 52. 

For this project I will create one (small, fun) game and update the project once each week. 

It is (obviously?) based on the infamous multicart Action 52 on NES and Sega Genesis. 

Currently refactoring to actually make it doable to get some version of each game done realistically once per week.
