# ECHO Idea

## What the idea is

So this would be based on Echo, the Simon game from Action 52, the Genesis version. So the thought would be that you can do primary, secondary colors and tints. 

So something like this: 
    B
R       Y
    S

L trigger -> tint
R trigger -> shade

The top of the buttons on the right, would be the primary colors, and then you press multiple together to produce secondary colors, then you can add L or R to produce tints. 

So you do something like, put in the sequence of commands and then press B (the key marked S) in order to "send the color" 

so red would be R -> S
purple would be R -> B -> S
lavendar would be R -> B -> L -> S
